# Falling hearts

An asset-free animation extracted from a personal Pygame project. Forty-five heart-shaped particles fall and drift sideways with independent speeds, phases and sizes. Pygame draws the hearts and the central rose using circles, ellipses, lines and polygons.

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python particles.py
```

Close the window or press Escape to exit.
